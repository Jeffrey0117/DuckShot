截圖，就是要快。

免費的 Windows 截圖工具。區域、全螢幕、視窗截圖，內建文字辨識，一鍵上傳分享。老舊筆電也順。

下載 Windows 版
Windows 10 / 11（64 位元）· 免費 · 更新記錄

能做什麼

三種截圖

區域、全螢幕、視窗。多螢幕時自動截游標所在的那一台。

秒開

按下快捷鍵約 0.1 秒出現，畫面乾淨、自動隱藏滑鼠游標。

文字辨識 OCR

框起來按 5，中英文都能抓，結果可直接複製。

一鍵分享

上傳圖床拿到連結並自動複製，也能存檔後一鍵分類到資料夾。

圖庫

截圖歷史一目了然，資料夾變動即時同步。

輕巧

為老舊電腦最佳化，安裝檔約 110 MB，不佔資源。

快捷鍵

區域截圖Alt + A
全螢幕截圖PrintScreen
視窗截圖Alt + W
截圖時：複製 / 儲存 / 上傳 / 連續 / 文字辨識1 2 3 4 5

快捷鍵都能在設定頁自訂。
